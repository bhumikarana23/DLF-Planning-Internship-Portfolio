# DLF Ltd. – Planning Internship Portfolio

## Overview

This repository presents a curated portfolio of selected work, learning outcomes and practical exposure gained during my internship with the **Planning Department at DLF Ltd.**

The internship provided practical exposure to construction planning, project progress monitoring, material consumption tracking and project documentation across large-scale real estate developments.

The portfolio is intended to demonstrate my understanding of construction planning processes, project coordination and execution monitoring.

## Internship Details

| Particular | Details |
|---|---|
| Organisation | DLF Ltd. |
| Department | Planning |
| Role | Planning Intern |
| Domain | Construction Planning & Project Monitoring |
| Project Exposure | Downtown Towers 5, 6, 7 & 8; Mall of India Phase 2, Gurugram |

## Key Responsibilities

- Prepared Daily Progress Reports (DPRs) to document construction activities and monitor project progress.
- Assisted in tracking material consumption and organising related project information.
- Maintained project spreadsheets and documentation to support planning and reporting activities.
- Gained on-site exposure to construction activities, execution processes and project coordination.
- Observed the role of planning and progress reporting in monitoring large-scale real estate developments.

## Project Exposure
